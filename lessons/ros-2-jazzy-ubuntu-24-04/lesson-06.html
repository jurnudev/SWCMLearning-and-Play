EP6

ROS 2 Launch Files

"เจาะลึกการทำงานของสคริปต์สั่งรันอัตโนมัติ"

1. ทำไมต้องมี Launch Files?

ในโลกของหุ่นยนต์จริง เราอาจต้องรันโปรแกรมย่อยๆ พร้อมกันนับสิบตัว Launch File คือสคริปต์ Python ที่ทำหน้าที่เป็น "ผู้จัดการระบบ" ช่วยเปิด Node ทุกตัวให้เราในคำสั่งเดียว

2. การสร้างไฟล์สคริปต์

สร้างโฟลเดอร์ launch และไฟล์ robot_app.launch.py ดังนี้:

robot_app.launch.py

from launch import LaunchDescription from launch_ros.actions import Node def generate_launch_description(): return LaunchDescription([ Node( package='my_robot_controller', executable='news_station', name='station_node' ), Node( package='my_robot_controller', executable='news_listener', name='listener_node' ) ])

3. เจาะลึกการทำงานของโค้ด

📦 การนำเข้า Library

เราระบุ LaunchDescription เพื่อสร้างใบสั่งงาน และ Node เพื่อบอกระบบว่าจะเปิดโปรแกรมตัวไหนจาก Package ไหน

🔑 ฟังก์ชัน generate_launch_description()

นี่คือหัวใจหลัก! ROS 2 จะมองหาฟังก์ชันชื่อนี้เสมอ ถ้าตั้งชื่ออื่น ระบบจะหาทางรันไฟล์นี้ไม่เจอ โดยเราต้อง return รายการของ Node ออกไปเป็น List [ ]

⚙️ ส่วนประกอบของ Node Action

package: ชื่อกล่องเก็บโค้ดที่เราสร้างใน EP5
executable: ชื่อเรียกที่เราลงทะเบียนไว้ใน setup.py
name: ชื่อที่เราต้องการให้ปรากฏในระบบ (สามารถเปลี่ยนชื่อได้ที่นี่โดยไม่ต้องแก้โค้ดหลัก)

4. ทำไมต้องแก้ setup.py?

"การเขียนไฟล์เสร็จ ไม่ได้หมายความว่าระบบจะหาเจอ"

ตามปกติระบบ ROS 2 จะมองหาไฟล์ที่อยู่ในโฟลเดอร์ install เท่านั้น การเพิ่มโค้ดใน data_files คือการสั่งให้ระบบก๊อปปี้ไฟล์ในโฟลเดอร์ launch ของเราไปวางในโฟลเดอร์ระบบด้วยทุกครั้งที่เราสั่ง colcon build

setup.py

# บรรทัดนี้บอกระบบว่า "ไปดึงไฟล์นามสกุล .py ทั้งหมดในโฟลเดอร์ launch มาติดตั้งด้วย" (os.path.join('share', package_name, 'launch'), glob(os.path.join('launch', '*launch.[pxy][yma]*'))),
⚠️ อย่าลืม import บรรทัดนี้ใช้ os และ glob ต้องมีที่ต้นไฟล์ setup.py:
import os
from glob import glob
และบรรทัดนี้ต้องอยู่ในลิสต์ data_files=[ ... ]

5. ลำดับการทำงานเมื่อสั่งรัน

1 System Check

ROS 2 เข้าไปหาไฟล์ในโฟลเดอร์ share ของระบบ

2 Execute Python

ระบบรันฟังก์ชัน generate_launch_description() เพื่ออ่านใบสั่งงาน

3 Multi-Run

ระบบสั่งเปิด Node ทั้งหมดที่ระบุไว้พร้อมกัน โดยรวมหน้าจอ Terminal มาไว้ที่เดียว

ทดสอบคำสั่งสุดท้าย

ros2 launch my_robot_controller robot_app.launch.py
"เพียงคำสั่งเดียว คุณจะเห็นหุ่นยนต์ทั้งระบบเริ่มทำงานทันที!"
