Lesson 02

การติดตั้ง Ubuntu และ ROS 2 Jazzy

"แยกการติดตั้งระหว่างเครื่องควบคุม (PC) และหุ่นยนต์ (Raspberry Pi)"

🛠️ ส่วนที่ 1: การลง OS (Ubuntu 24.04 LTS)

💻 สำหรับ Computer (Client)

ใช้สำหรับเขียนโค้ด, จำลองภาพ (RViz) และควบคุมหุ่นยนต์

  • ✅ ลงแบบ Ubuntu Desktop (มีหน้าจอ GUI)
  • ✅ พื้นที่แนะนำ 64GB ขึ้นไป
  • ✅ แนะนำให้ลงแบบ Dual Boot หรือเครื่องเปล่า

🍓 สำหรับ Raspberry Pi (Robot)

ใช้ประมวลผลบนตัวหุ่นยนต์โดยตรง เน้นประหยัดทรัพยากร

  • ✅ ลงแบบ Ubuntu Server (Command Line เท่านั้น)
  • ✅ MicroSD Card Class 10 (A1/A2) 16GB-32GB
  • ✅ ใช้โปรแกรม Raspberry Pi Imager ในการลง
[ กราฟิกแสดงการเชื่อมต่อ ]

🤖 ส่วนที่ 2: ขั้นตอนการติดตั้ง ROS 2 Jazzy

💡 คำแนะนำ: ขั้นตอน A และ B ต้องทำทั้งบนคอมพิวเตอร์ และ Raspberry Pi

A - ตั้งค่าภาษาของระบบ (Set Locales)

sudo apt update && sudo apt install locales sudo locale-gen en_US en_US.UTF-8 sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8 export LANG=en_US.UTF-8

B - เพิ่มแหล่งเก็บซอฟต์แวร์ (Setup Sources)

sudo apt install software-properties-common -y sudo add-apt-repository universe -y sudo apt update && sudo apt install curl -y sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

C - เลือกประเภทการติดตั้งให้เหมาะสม

💻 Desktop Version (สำหรับ PC)

ติดตั้งครบทุกอย่าง ทั้ง Core, เครื่องมือจำลอง (RViz, Gazebo) และ Tutorial

sudo apt update sudo apt install ros-jazzy-desktop
🍓 ROS-Base (สำหรับ Raspberry Pi)

ติดตั้งเฉพาะหัวใจหลัก ไม่รวม GUI ช่วยประหยัดพื้นที่ SD Card และ CPU

sudo apt update sudo apt install ros-jazzy-ros-base

D - ตั้งค่าทางลัด (Environment Setup)

ทำเหมือนกันทั้งสองเครื่อง เพื่อให้พิมพ์คำสั่ง ros2 ได้ทันที:

echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc source ~/.bashrc

📡 ทดสอบการเชื่อมต่อ (DDS Test)

"ลองส่งข้อมูลจาก Raspberry Pi มาที่หน้าจอคอมพิวเตอร์"

1. ที่ฝั่ง Raspberry Pi (Robot):
สั่งให้หุ่นยนต์ประกาศข้อความ "Hello World"

ros2 run demo_nodes_cpp talker

2. ที่ฝั่ง Computer (Desktop):
เปิดเครื่องรับฟังข้อความ (ต้องอยู่ในวง WiFi เดียวกัน)

ros2 run demo_nodes_py listener
