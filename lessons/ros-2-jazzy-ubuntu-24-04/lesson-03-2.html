EP3.2

Professional Remote Workflow

"เชื่อมต่อคอมพิวเตอร์กับหุ่นยนต์ ให้เป็นหนึ่งเดียวด้วย VS Code"

ใน EP นี้เราจะหยุดการถอด SD Card หรือการต่อจอแยกให้ Raspberry Pi
แต่เราจะใช้ Remote-SSH เพื่อควบคุมทุกอย่างจากหน้าจอคอมพิวเตอร์เครื่องเดียว!

1

ตามหาที่อยู่หุ่นยนต์ (Finding IP Address)

ก่อนจะเชื่อมต่อได้ เราต้องรู้ก่อนว่า Raspberry Pi ของเราอยู่ที่ไหนในวงเครือข่าย (WiFi เดียวกัน)

📍 พิมพ์ที่: Terminal บน Raspberry Pi (หรือต่อจอครั้งสุดท้าย)
Terminal
hostname -I

ผลลัพธ์จะเป็นตัวเลข เช่น 192.168.1.45 นั่นคือ "บ้านเลขที่" ของหุ่นยนต์เรา

💡 Tip: แนะนำให้ใช้แอป Fing ในมือถือ หรือโปรแกรม Advanced IP Scanner เพื่อหา IP ของ Pi ได้โดยไม่ต้องต่อจอครับ
2

ติดตั้งเครื่องมือ Remote-SSH

  1. เปิด Visual Studio Code บนคอมพิวเตอร์ของคุณ (Client)
  2. ไปที่เมนู Extensions (รูปสี่เหลี่ยมด้านซ้ายมือ)
  3. ค้นหาคำว่า "Remote - SSH" โดย Microsoft แล้วกด Install
3

เริ่มการเชื่อมต่อ (Establishing Connection)

  1. กดปุ่มสีน้ำเงินเล็กๆ มุมซ้ายล่างของ VS Code ><
  2. เลือก Connect to Host... → Add New SSH Host...
  3. พิมพ์คำสั่ง: ssh [ชื่อuser]@[เลขIP]
SSH Command
ssh pi@192.168.1.45
  1. เลือกไฟล์ Config ตัวแรก แล้วกด Connect ที่มุมขวาล่าง
  2. ใส่รหัสผ่านของ Raspberry Pi (ค่าเริ่มต้นมักจะเป็น ubuntu หรือตามที่อาจารย์ตั้งไว้)

🔄 วงจรการทำงาน: เขียนที่เครื่อง รันที่หุ่น

เมื่อเชื่อมต่อสำเร็จ คุณจะเห็นชื่อ SSH: [IP] ที่มุมล่างซ้าย ต่อไปนี้คือขั้นตอนการทำงานจริง:

1. Write & Save

เขียนโค้ดใน VS Code แล้วกด Save ไฟล์จะถูกบันทึกที่ Raspberry Pi ทันที

2. Build

เปิด Terminal ใน VS Code (Ctrl + `) แล้วสั่ง colcon build บนตัวหุ่น

3. Run

ใช้ Terminal เดียวกันสั่ง ros2 run เพื่อดูหุ่นยนต์เคลื่อนที่!

🏆 สรุป: ทำไมเราถึงต้องใช้เครื่องมือนี้?

  • ✔ ไม่ต้องพกจอ คีย์บอร์ด เม้าส์ ไปที่ตัวหุ่นยนต์
  • ✔ เขียนโค้ดได้รวดเร็วด้วยฟีเจอร์ Auto-complete ของ VS Code
  • ✔ เปิด Terminal ได้หลายหน้าพร้อมกันเพื่อดู Log หลายๆ Node
  • ✔ บริหารจัดการไฟล์ในหุ่นยนต์ได้ง่ายเหมือนใช้ Windows Explorer
